El manifiesto, en pocas palabras

Es la etiqueta de cada versión de los datos: un archivo pequeño, sin datos de centros, que dice cuándo se generó la publicación, cuántos centros tiene y cómo es cada archivo.

Sirve para saber si hay datos nuevos sin descargarlo todo (basta con leerlo y comparar la fecha o la huella con las de la última vez) y para comprobar que una descarga ha llegado entera.

CampoQué le dice
generated_atCuándo se generó esta versión de los datos.
schema_versionLa versión del formato. Si cambia, revise cómo lee los archivos.
records · active_recordsCuántos centros hay en total y cuántos siguen abiertos.
files.<archivo>.bytesEl tamaño exacto del archivo. El que descargue debe medir lo mismo.
files.<archivo>.recordsCuántas filas tiene ese archivo.
files.<archivo>.sha256Su huella. Si coincide con la de su copia, la descarga está completa y sin cambios.

Qué significa cada campo

Los más usados de centros.csv y centros.json. La lista completa de campos está en el README.

CampoQué contiene
CodigoCódigo oficial del centro, ocho dígitos. Léalo siempre como texto.
DenominacionNombre actual del centro.
DesEtapaCentroTipo de centro abreviado: CEIP, IES, CEPA, CER…
Municipio · IslaMunicipio e isla, en mayúsculas.
CentroProfesoresCodigoCódigo del CEP al que está adscrito. El CEP es a su vez un centro del listado.
EOEPEquipo de orientación de zona, con código y nombre.
ZonaInspeccionCodigoZona de inspección educativa.
Latitud · LongitudUbicación en grados decimales. Falta en algunos centros.
Activo1 si el centro sigue abierto; 0 si ya no existe y se conserva como histórico.
FechaBaja · CodigoSustituidoPorCuándo cerró y qué código lo sustituye, si se sabe.
DenominacionesAnterioresNombres anteriores, del más reciente al más antiguo, separados por | .
CamposCorregidosCampos cuyo valor se ha corregido a mano respecto a la fuente original.

Ejemplos

Rellenar un desplegable con los centros abiertos de una isla, usando el archivo ligero.

const URL = "https://ateeducacion.github.io/listado-centros-educativos-canarias/centros.min.json";
const centros = await fetch(URL).then((r) => r.json());

const tenerife = centros
  .filter((c) => c.active && c.island === "TENERIFE")
  .map((c) => new Option(c.name, c.code));

document.querySelector("#centro").append(...tenerife);

Cargar el listado completo con pandas. Lea el código como texto para no perder ningún dígito.

import pandas as pd

URL = "https://ateeducacion.github.io/listado-centros-educativos-canarias/centros.csv"
centros = pd.read_csv(URL, dtype={"Codigo": str})

abiertos = centros[centros["Activo"] == 1]
print(abiertos.groupby("Isla").size())

Descargar el CSV y comprobar que ha llegado entero comparando su huella con la del manifiesto.

BASE=https://ateeducacion.github.io/listado-centros-educativos-canarias
curl -sO "$BASE/centros.csv"

esperada=$(curl -s "$BASE/manifest.json" | jq -r '.files["centros.csv"].sha256')
echo "$esperada  centros.csv" | shasum -a 256 -c -

Antes de empezar

  • El listado incluye centros que ya no existen. Si solo quiere los abiertos, filtre por Activo = 1 (o active en el archivo ligero).
  • Trate el código como texto, nunca como número, y úselo para enlazar registros: el nombre puede cambiar y el código no.
  • No hay límite de uso, pero si su aplicación consulta los datos a menudo, lea primero el manifiesto y descargue los archivos solo cuando cambien.

Enlazar a un centro

Para llevar a alguien a la ficha de un centro, añada su código a la dirección del buscador. Para abrir la calculadora de distancias con ese centro como salida, use origin.

…/listado-centros-educativos-canarias/?centro=35002911
Ficha del IES Pérez Galdós.
…/distancias_centros_educativos_canarias/?origin=35002911
Calculadora con ese centro como salida.
